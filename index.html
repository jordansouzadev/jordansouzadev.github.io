Projeto e construo sistemas full stack que resolvem problemas reais de negócio — com arquitetura pensada para durar, não só para funcionar na demo.

Os dois projetos deste portfólio comprovam isso na prática: sistemas em produção real, com autenticação, testes automatizados e documentação completa — um motor de agendamento para um estúdio de beleza e uma plataforma SaaS de gestão para academias.

Sistemas em produção

Dois projetos full stack completos, do modelo de dados até o painel administrativo.

Ariane Paiva Studio

// site institucional + agendamento online

Sistema completo de presença institucional e agendamento online para um estúdio de manicure, pedicure e nail art. Inclui site público, motor de agendamento com verificação real de disponibilidade e painel administrativo completo.

  • Fluxo de agendamento em 5 passos, sem necessidade de conta
  • Disponibilidade calculada no backend (horário, bloqueios, agendamentos existentes)
  • Painel admin: agenda dia/semana/mês, clientes, serviços, galeria e depoimentos
  • Autenticação JWT com controle de acesso

Iron Manager

// plataforma SaaS de gestão para academias

Plataforma SaaS white label de gestão para academias, desenvolvida para a CT Iron House. Backend construído seguindo Clean Architecture, com forte cobertura de testes e pipeline de qualidade de código.

  • Arquitetura em camadas (Clean Architecture) com separação clara de responsabilidades
  • Bootstrap seguro de super admin via script dedicado (nunca via API pública)
  • Paridade de produção local via Docker + PostgreSQL
  • Testes de integração e cobertura via pytest, lint e types via ruff/mypy
